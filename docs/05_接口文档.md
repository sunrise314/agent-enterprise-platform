# 05 接口文档

> biz-platform REST API 设计，统一前缀 `/api`，统一鉴权。

## 5.1 通用约定

- 认证：请求头 `Authorization: Bearer <JWT>`
- 响应统一格式：
```json
{ "code": 0, "message": "ok", "data": {} }
```
- 错误码：`code != 0` 表示失败
- 分页参数：`page` / `size`

## 5.2 会话 & Agent 接口

### POST /api/agent/chat
对话（流式 SSE 或非流式）

**请求体：**
```json
{
  "query": "公司年假制度是什么",
  "sessionKey": "可选，空则新建会话",
  "stream": true
}
```

**响应（非流式）：**
```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "sessionKey": "s-xxx",
    "answer": "根据公司制度第X条...",
    "citations": [{"title": "员工手册", "section": "年假条款"}],
    "toolCalls": [{"tool": "kb_search", "status": "success"}],
    "metrics": {"tokenIn": 320, "tokenOut": 180, "latencyMs": 2300}
  }
}
```

### GET /api/agent/session
会话列表（分页）
`GET /api/agent/session?page=1&size=20`

### POST /api/agent/session/{sessionKey}/reset
重置 / 清空会话上下文

## 5.3 知识库接口

### POST /api/kb/upload
上传文档入库（multipart）

**参数：** `file`（文件）、`kbId`、`tenantId`（由 Token 决定）

### GET /api/kb/doc?tenantId=&page=&size=
文档列表

### DELETE /api/kb/doc/{docId}
删除文档（含向量）

### POST /api/kb/search
知识库检索（调试用，返回命中片段）

**请求体：**
```json
{ "query": "报销流程", "topK": 5 }
```
**响应：** 命中片段数组（含来源、分数）

## 5.4 评估接口

### POST /api/eval/run
触发评估批次
```json
{ "name": "v1.0-regression", "testcaseFilter": {"type": "badcase"} }
```

### GET /api/eval/run/{runId}
查看批次状态与汇总指标
```json
{
  "code": 0,
  "data": {
    "runId": 12,
    "status": "done",
    "total": 100, "success": 91, "fail": 9,
    "metrics": {
      "taskCompletionRate": 0.91,
      "toolCallAccuracy": 0.95,
      "hallucinationRate": 0.04,
      "p95LatencyMs": 4800,
      "avgTokenTotal": 520
    }
  }
}
```

### GET /api/eval/run/{runId}/detail
逐条 case 结果明细（失败原因）

### POST /api/eval/testcase
新增测试用例

## 5.5 权限 & 管理接口

### POST /api/auth/login
登录，返回 JWT
```json
{ "username": "admin", "password": "***" }
```

### GET /api/auth/me
当前用户信息（含角色、可用工具）

### GET /api/audit?action=&userId=&page=&size=
审计日志查询

## 5.6 错误码示例

| code | 说明 |
|---|---|
| 0 | 成功 |
| 401 | 未认证 |
| 403 | 无权限（RBAC） |
| 429 | 限流 |
| 500 | 服务异常 |
| 504 | Agent 执行超时 |

## 5.7 流式输出（SSE）格式

`Content-Type: text/event-stream`

```
event: tool
data: {"tool":"kb_search","status":"calling"}

event: message
data: {"delta":"根据公司制度第"}

event: done
data: {"sessionKey":"s-xxx","citations":[...]}
```
