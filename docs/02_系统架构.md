# 02 系统架构

## 2.1 分层架构（自底向上）

```
┌─────────────────────────────────────────────────────────────┐
│ 接入层：API 网关（SpringBoot）鉴权、限流、输入校验、流式输出 │
├─────────────────────────────────────────────────────────────┤
│ 业务应用层（biz-platform 自研闭源）                          │
│  ├─ RAG 知识库模块（文档 ingestion、分块、多路检索、重排）   │
│  ├─ 业务工具模块（SQL 查询、文件导出、检索工具）             │
│  ├─ Agent 评估模块（评估 Runner、测试集、指标存储）          │
│  ├─ 权限 & 审计模块（RBAC、多租户、审计日志）                │
│  └─ 可观测模块（事件埋点、日志、指标上报）                   │
├─────────────────────────────────────────────────────────────┤
│ Agent 底座层：AgentScope-Java（Apache2.0，上游开源）         │
│  ├─ HarnessAgent / ReActAgent 编排引擎                      │
│  ├─ Tool 定义、MCP 协议支持                                  │
│  ├─ Agent 事件流、会话 State 管理、Checkpoint 持久化        │
│  └─ 模型适配层（通义千问 / Ollama / vLLM）                   │
├─────────────────────────────────────────────────────────────┤
│ 基础设施层                                                  │
│  PostgreSQL / Redis / Milvus / OpenSearch / 文件存储        │
└─────────────────────────────────────────────────────────────┘
```

## 2.2 模块依赖关系

1. `biz-platform` 以 Maven 依赖方式引入 `agentscope-java` 作为底座；
2. Agent 业务工具、RAG 检索工具，通过 AgentScope-Java 的 Tool 接口注册进 Agent；
3. Agent 所有生命周期事件（思考、工具调用、异常）通过事件监听器抛出，供评估模块、监控模块消费；
4. 评估模块**不侵入 Agent 执行主流程**，属于旁路采集指标，保证对线上主链路零侵入。

## 2.3 核心数据流

```
用户请求
  → API 网关鉴权（RBAC + 租户校验 + 限流）
  → 构建 Agent RuntimeContext（sessionId / userId / tenantId）
  → HarnessAgent 执行
      → Agent 思考（ReAct 循环）
      → 判断是否调用工具
      → 执行自定义业务 Tool（RAG 检索 / SQL 查询 / 文件导出）
      → 拿到结果继续推理
  → Agent 执行事件异步上报到评估 / 监控
  → 返回最终答案，保存会话 state 到 Redis
```

## 2.4 扩展设计原则

1. **底座扩展**：优先使用 SPI、事件监听、自定义 Tool，尽量不修改 agentscope-java 源码；
2. **模块解耦**：RAG、评估、权限模块独立，可单独开启/关闭；
3. **模型解耦**：模型配置外置，一键切换私有化大模型；
4. **可观测旁路**：埋点与指标上报不阻塞主链路。

## 2.5 技术栈明细

| 类别 | 选型 | 说明 |
|---|---|---|
| 语言 | Java 17 | JDK17+（AgentScope-Java 硬性要求） |
| 框架 | SpringBoot 3.x | 业务服务、网关 |
| Agent 编排 | AgentScope-Java | HarnessAgent、ReAct、MCP、事件流 |
| 响应式 | Project Reactor | 异步非阻塞 |
| 数据库 | PostgreSQL | 业务、评估指标、测试用例 |
| 缓存 | Redis | 会话状态、限流 |
| 向量库 | Milvus | 向量检索 |
| 检索引擎 | OpenSearch | BM25 关键词检索 |
| 可观测 | Micrometer + Prometheus + Grafana | 指标看板 |
| 部署 | Docker Compose | 一键部署 |

## 2.6 多环境隔离

- 开发环境：本地 Docker Compose
- 测试环境：独立 PostgreSQL / Redis / Milvus
- 生产环境：私有化部署，模型与数据库均内网化，不依赖外网
