# 09 迭代规划

> 版本演进路线，明确每个版本的功能范围与验收标准。

## 9.1 版本规划总览

| 版本 | 主题 | 核心范围 | 状态 |
|---|---|---|---|
| v0.1 | 骨架搭建 | 目录、pom、基础 SpringBoot 工程 | ✅ 当前 |
| v1.0 | 最小商用交付 | Agent 核心 + RAG + 工具 + 评估 + 权限 + 网关 + Docker | 🎯 目标 |
| v1.1 | 能力增强 | 多 Agent 协作（A2A）、HITL 人机介入、前端管理界面 | 规划 |
| v1.2 | 生产高可用 | K8s 部署、高可用集群、多副本 | 规划 |

## 9.3 验收标准（v1.0）

- 任务完成率 ≥ 90%
- 工具调用准确率 ≥ 95%
- 幻觉率 ≤ 5%
- P95 端到端延迟 ≤ 5s
- 支持私有化部署，不依赖外网模型
- 评估模块可一键跑回归，输出对比报告

## 9.5 文档迭代机制

- 每完成一个模块，同步更新对应 `docs/03_模块设计/*.md`
- 每版本结束，更新 README 版本状态
- 面试模拟按模块逐个深挖，记录 Q&A 到对应文档「面试要点」节
