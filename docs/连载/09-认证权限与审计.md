# 09 认证、权限与审计

> 第九篇讲安全三件套：JWT 签发校验、路径→权限映射、审计埋点选点。

## JWT：签发与校验

`JwtUtil` 负责 Token 的签发和解析：

- **签发**：登录成功后把 `userId`、`tenantId`、`roles` 写进 payload，用 HMAC-SHA256 签名；
- **校验**：`AuthInterceptor` 在请求入口拦截，校验签名、过期时间、解析 payload 里的角色列表；
- **过期**：默认 2 小时，生产可按安全要求调短。

签发代码的关键：

```java
public String generate(Long userId, String tenantId, List<String> roles) {
    return Jwts.builder()
            .setSubject(String.valueOf(userId))
            .claim("tenant", tenantId)
            .claim("roles", roles)
            .setIssuedAt(new Date())
            .setExpiration(new Date(System.currentTimeMillis() + ttlMillis))
            .signWith(Keys.hmacShaKeyFor(secret.getBytes()), SignatureAlgorithm.HS256)
            .compact();
}
```

## RBAC：路径→权限映射

我的权限模型很朴素：**路径正则 + HTTP 方法 + 角色白名单**。`SecurityConfig` 里配：

```java
http
    .authorizeHttpRequests(auth -> auth
        .requestMatchers("/api/public/**").permitAll()
        .requestMatchers("POST", "/api/agent/chat/**").hasAnyRole("agent:chat")
        .requestMatchers("POST", "/api/kb/**").hasAnyRole("kb:write")
        .requestMatchers("GET", "/api/metrics/**").hasAnyRole("metrics:read")
        .anyRequest().denyAll()
    )
    .addInterceptor(new AuthInterceptor(jwtUtil));
```

四个角色覆盖主要场景：

| 角色 | 权限 |
|---|---|
| `agent:chat` | 发起对话、流式 chat |
| `kb:write` | 上传文档、删除知识库 |
| `metrics:read` | 查看指标、审计日志 |
| `admin` | 全部 |

实测权限矩阵：

| 请求 | 用户角色 | 结果 |
|---|---|---|
| POST /api/agent/chat | agent:chat | 200 |
| POST /api/agent/chat | kb:write（无 agent:chat） | 403 |
| GET /api/metrics/summary | metrics:read | 200 |
| GET /api/metrics/summary | agent:chat（无 metrics:read） | 403 |
| POST /api/kb/upload | kb:write | 200 |
| POST /api/kb/upload | admin | 200 |
| POST /api/kb/upload | agent:chat | 403 |

## 审计埋点：选点原则

审计日志不能什么都记——记太多噪音大、查不到；记太少合规不过。我的选点原则：**只记有业务语义的动作**，具体三个条件：

1. **有持久化副作用**：上传文档（创建向量）、删除会话、修改角色；
2. **有成本影响**：Agent chat（花 token 要钱）、LLM judge（评估也要花 token）；
3. **有合规要求**：SQL 沙箱查询（可能查敏感数据）、认证登录。

具体埋点：

```java
// AuditLogger.java — 环形缓冲，生产升级为落库
public void audit(String action, String tenantId, Long userId, long costMs, Map<String, Object> extras) {
    AuditEntry e = new AuditEntry(now(), action, tenantId, userId, costMs, extras);
    ringBuffer.add(e);  // 内存环形缓冲，保留最近 2000 条
}
```

实际调用点举几个：

- `AgentServiceImpl.chat()` → `audit("agent.chat", tenant, userId, cost, extras)`
- `KbController.upload()` → `audit("kb.upload", tenant, userId, cost, extras)`
- `SqlGuard.beforeQuery()` → `audit("sql.query", tenant, userId, cost, extras)`
- `AuthController.login()` → `audit("auth.login", tenant, userId, cost, extras)`
