## 写作约定

1. 第一人称「我」，决策复盘视角：为什么这么选、放弃了什么、坑在哪；
2. 每章一个可复现的验证动作 + 真实数字，不写「理论上」；
3. 章节内代码截取自 `src/biz-platform`，讲思路不放全量；
4. 禁词：小哈。
