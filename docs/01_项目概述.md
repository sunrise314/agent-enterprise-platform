# 01 项目概述

## 1.1 业务目标

构建私有化企业智能体平台，赋能企业内部员工：

1. 企业文档知识库问答（RAG）
2. Agent 自主规划，调用业务工具（数据库查询、文件导出）
3. 可量化评估 Agent 效果，支持版本回归测试
4. 多租户隔离，RBAC 权限，操作审计日志，满足政企安全要求

## 1.2 适用业务场景

- 企业内部制度、合同、技术文档智能问答
- 业务数据自助查询（只读 SQL 沙箱）、报表导出
- 复杂多步骤任务，Agent 自动串联多个工具完成

## 1.3 非功能需求（商用交付硬性指标）

1. 私有化部署，不依赖外网模型 API；支持本地私有化大模型
2. 会话持久化，任务中断可续跑
3. 安全：Prompt 注入防护、租户数据隔离、审计日志
4. 稳定性：LLM 调用超时、重试、熔断、限流，防止 Agent 无限循环调用工具
5. 可观测：全链路 trace，指标采集，Grafana 看板
6. 可评估：批量测试集，自动评估，bad case 沉淀，版本回归

## 1.4 边界范围（v1.0）

**✅ 包含：**
- HarnessAgent + ReAct 编排
- 自定义 Tool、MCP 工具接入
- RAG 完整文档入库、分块、多路检索 RRF 重排
- Agent 评估 Runner、LLM-as-judge、指标统计
- RBAC 多租户、审计日志
- REST API、流式输出
- Docker Compose 部署脚本

**❌ v1.0 暂不实现：**
- 前端 Web 管理界面（仅后端 API，可后续新增）
- 复杂多 Agent 协作（子 Agent、A2A 放到 v1.1）
- 高可用集群（K8s 放到 v1.2）

## 1.5 交付模式

1. **镜像交付**：Docker 镜像包，客户直接部署，不交付源码
2. **源码授权交付**：交付整套源码（底座 + 自研业务代码），合同明确底层依赖 AgentScope-Java Apache2.0 协议

## 1.6 衡量指标（上线验收口径）

| 指标 | 目标 |
|---|---|
| 任务完成率 | ≥ 90% |
| 工具调用准确率 | ≥ 95% |
| 幻觉率（无来源支撑输出占比） | ≤ 5% |
| P95 端到端延迟 | ≤ 5s |
| 平均单轮 token 消耗 | 可量化上报，用于成本审计 |
